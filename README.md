# Project Clicky AI
Screen-aware Groq-powered desktop copilot (Electron, macOS-first). See `docs/STATUS.md` for what works and what does not, `docs/SETUP.md` to run, `docs/ARCHITECTURE.md` for design.

## HeyClicky Website Recreation
The repository contains an authentic, pixel-perfect recreation of the official [heyclicky.com](https://www.heyclicky.com/) website in `website/`.

### Run Website Locally
```bash
# From repository root
npm run web

# Or directly in website directory
cd website
npm run dev
```
Open [http://localhost:3006](http://localhost:3006) to explore the website.
